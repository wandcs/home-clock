# 使用说明

## 首次配置

通过触屏配置Wi-Fi，保存成功后自动联网校时。随后可以设置天气位置，也可先使用时钟。未校时时显示未知时间，不按保存的旧时间触发闹铃。

天气位置支持城市/区县，可用汉字、拼音全拼或简拼联想，容忍有限常见错拼。选择后确认具体地点；离线也可选择，天气待联网后取得。

## 三个页面

- 时钟：时间、日期、参考天气、室内环境和下一闹铃。
- 七天天气：逐日天气、温度范围和一项重点提示。
- 闹铃：列表、启用开关、新增与编辑。

左右横滑首尾循环。浏览页闲置后回主页，编辑页保留草稿。没有启用闹铃时，主页不显示闹铃占位说明。

## 天气与重点提示

正常天气由Open-Meteo提供。主源缺少当前或逐日数据时，已配置的MET备源按组、按日期补缺；本轮有效主源优先。MET温度前的“约”表示参考温区，天气页和来源页会说明差异，不能当作标准全天高低温。今天时段不完整时保留同日有效缓存，或显示未知。

主页温度范围旁、七天页每一天各保留一项重点提示。更强风优先；冻雨、冰雹、雷雨和较强雨雪优先于一般较强风，其后才是日强紫外线、降水概率和普通风。雷雨天气的重点短值显示“雷电”，与天气名称区分；每一天只使用该日期的有效预报。降水概率不表示雨量或雨强，普通雨雪的有效0%仍保留。

“空气欠佳”只在主页代表当前小时，不用当前值填写未来各日；数据来自CAMS全球模型，经Open-Meteo提供，按美标AQI超过100选取提示，不是中国监测站AQI或官方霾预警。每3小时至多尝试一次，缓存按小时选择有效值；失效或取数失败不会影响时钟、闹铃和其他有效天气数据。来源与时间可在天气来源页查看。

## 闹铃

重复方式为仅响一次、每天、工作日；工作日采用中国大陆年度放假调休表，缺表时按既定回退处理。

小时和分钟采用数字输入。明确重新开启，或修改已开启条目的时间/重复方式，都会重新安排。过去的时刻取下一合法日期，不立即补响。

一次性条目结束后关闭并保留，循环条目保留未来计划。响铃可点击“停止”，无人操作3分钟结束，没有“稍后再响”。

在“设置 → 闹铃音量”拖动调节并同步试听，松手或离开停止并保存。0为静音；正常到点温和渐强。数值不是声压或主观响度百分比。

## 亮度、断网与断电

BH1750控制自动背光。亮度页仅临时预览，返回恢复自动。户外昼夜按地点与日期计算，低照度状态还取决于本地环境光。

持续供电且已校时后，断网仍能走时、读传感器和执行本地闹铃；天气缓存有新鲜度/不可用表达。

无备用电池。断电期间不运行，来电后读取配置并重新校时，错过闹铃不补响。Wi-Fi和共享设置保存在设备本地，天气查询只提交所需地点信息。
