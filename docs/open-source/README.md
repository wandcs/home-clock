# 开源源码快照

本项目的完整开发仓库保留阶段设计、实验和实机证据。[公开仓库](https://github.com/wandcs/home-clock)采用审阅后的文件快照，不携带原开发Git历史、个人环境或设备记录；原历史在本地保留，不重写。

## 快照包含什么

- 当前应用、功能模块与纯C核心，本板BSP及固定依赖元数据。
- 正常构建所需的字体、图标、地点索引、天气字段和原创音源。
- 公共构建/检查入口、四组既有C fixture及音源重建工具。
- 当前使用、硬件、构建、架构文档和完整许可/署名文本。
- README使用的四张静态图、两段动图；主页和七日图更新为当前UI，其余天气/闹铃示例及动图保留既有来源。均为实际LVGL宿主渲染与公开合成数据，模拟手势不作为实机性能测评。

不会选入.local、Wi-Fi/联系配置、SDK/managed缓存、构建目录、旧固件、实机证据、研究响应或内部会话任务。历史设备脚本没有因导出而删除，也不会被改成不检查身份就烧录。

## 维护者生成快照

在已提交审阅改动、工作树干净的Git checkout中运行：

~~~text
python tools/export-source.py --output .local/public-source-new
~~~

输出必须是.local下一个尚不存在的新目录。工具按显式范围选择已跟踪文件、扫描保留文本中的常见身份/秘密模式、逐文件校对摘要并写SOURCE_MANIFEST.json；PNG/GIF仅按明确的六个定稿路径准入，保留原字节，媒体内容和来源另外审阅；不初始化Git、不连接设备、不发布，也不覆盖已有目录。

这是有界检查，不替代来源归属和人工范围核对。第三方许可证中的原作者联系/版权需要保留。完整开发仓库中的审计细节位于docs/open-source/audit.md，快照不带其内部路径清单。

## 验证和发布

从新快照目录运行[源码检查与正式构建](../building.md)，不能使用原工作区的构建产物冒称快照可构建。验证时写明SDK和缓存是否复用；源码干净不等于已经在全新电脑重装环境。

首次发布已建立独立公开历史。后续将审阅快照中的选定文件更新到公开仓库工作区，保留已有提交再普通提交/推送；不重新初始化或强推替换公开历史，也不直接推送完整开发仓库或其分支。源码更新与预编译固件Release分别处理。

项目自有内容采用MIT，第三方归属见[总清单](../../THIRD_PARTY_NOTICES.md)和[地点数据来源](data-sources.md)。历史release_ready字段不直接当作许可证或当前覆盖认证。再生成整套字体/地点/天气字段所需的历史制作流水线不属于公共首次构建前置；快照包含实际可编译资源、原创音源与首页专用字形的重建入口。首页字形来源、固定摘要和离线生成方法见[资源清单](../../assets/application/home-assets.json)，日常固件构建直接使用已生成资源。
